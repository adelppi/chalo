# ADR-0010: マスコット「チャロくん」は静的アセットで扱う（アニメーションを持たない）

- ステータス: 採用
- 関連: adr/0016, features.md 10.1

## コンテキスト

ブランドの核としてマスコット「チャロくん」（犬×たぬき。素材は顔・しっぽ・足跡）を据える。chalo（=行こう）と足跡（=旅の証）がコンセプトと噛み合う。

当初は Rive で「揺れ・瞬き程度」の控えめなアニメーションを付ける方針だった。しかし v1 を静的アセット（画像・GIF）だけで出荷したところ、スプラッシュ・空状態・ローディングのいずれも体裁が成立した。一方で `rive-react-native` はネイティブ依存であり、Expo Go では動かず Dev Client / EAS Build が要る、ランタイム自体は OTA で更新できない（`adr/0006`）といったコストがかかる。

## 決定

**マスコットは静的アセットのみで表示し、アニメーションは持たない。** Rive は採用しない。

- 出番：スプラッシュ／ローディング／空状態（0件）で、顔・しっぽ・足跡の静的アセットを置く。
- 「控えめに動かす」ためだけにネイティブ依存を1つ増やすことはしない。

## 結果

- 良い点：ネイティブ依存が1つ減り、OTA で差し替えられる範囲が広がる。ビルド・審査の制約も減る。
- 留意点：動きによる情緒的な演出は持てない。静止画のトーンと配置で世界観を担保する。

## デザイン原則（明文化）

アニメーションを持たなくても、マスコットの扱い方の原則は変わらない。

- 主張は控えめ。ユーザーの操作を妨げない。
- ライトモードのみ（`non-functional.md`）。
- チャロくんは急かさず寄り添うトーン。通知の思想（煽らず、終わる前に知らせる）と一致させる。
